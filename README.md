# 🛠️ Awesome GitHub Utils

A collection of handy utility scripts for developers.

## Features

- **`greet.py`** – A friendly greeting script that welcomes you by name.
- **`file_organizer.py`** – Organize files in a directory by extension.
- **`json_formatter.py`** – Pretty-print JSON from the command line.

## Quick Start

```bash
python greet.py --name "World"
# Hello, World! 👋
```
